# PlayableStudio：一秒八刀三场景试玩

这是一个可离线运行的 HTML5 动作试玩项目。玩家控制角色移动，让环绕身体顺时针旋转的刀刃与敌人拼刀，沿剧情路线收集资源、变身并连续通过三个场景。

项目保留完整开发源码、原始素材、自动测试、构建工具，以及低于 5 MB 的单 HTML 成品。

## 立即试玩

1. 下载 [`dist/一秒八刀_三场景_单文件.html`](dist/一秒八刀_三场景_单文件.html)。
2. 使用 Chrome 或 Edge 打开。
3. 点击画面一次以启用声音，然后拖动摇杆、使用鼠标，或按方向键/WASD 开始游戏。

单 HTML 已内嵌三个场景和全部运行素材，不需要服务器或网络。

需要修改源码、重新构建或运行全部测试时，请下载 `release/`中的分卷和 `合并完整项目.ps1`。把这些文件放在同一目录后运行脚本，即可得到 `PlayableStudio-complete-project.zip`。仓库中的源码和文档可直接浏览，原始媒体与压缩工作副本统一收在完整项目包中，避免数百个动画帧让 GitHub 页面难以浏览。

## 主要功能

- 三个剧情连续衔接的动作场景。
- 鼠标、触摸、方向键和 WASD 多种操作方式。
- 刀刃顺时针连续旋转、按等级碎裂、脱战后平滑补圆。
- 白刃、绿刃、金刃、红刃、紫刃和彩刃等资源与战斗阶段。
- 半身合体、肌肉悟空、黄衣金发悟空等剧情变身。
- 胖虎、酱爆、海神、毒液、巨人、魔人、哥布林、momo 和斧头帮等敌人。
- 失败重试、真实传送门换场景、音效动效和跨场景连续 BGM。
- 独立开发页、地图预览、自动测试和确定性单文件构建。

## 操作速查

| 设备 | 操作 |
|---|---|
| 电脑 | 方向键或 WASD 移动 |
| 鼠标 | 在画面中按住并拖动虚拟摇杆 |
| 手机/平板 | 触摸并拖动虚拟摇杆 |
| 声音 | 首次点击、触摸或按键后开始播放 |
| 重试 | 失败后点击“重试” |

角色自动用旋转刀刃攻击，玩家只负责移动和走位。

## 开发与构建

项目使用原生 HTML、CSS、Canvas 和 JavaScript，不需要 npm 安装。

```powershell
python tools/build_optimized_assets.py
python tools/build_single_html.py
python tests/single-html-build.py
node tests/single-html-browser.js
```

素材压缩需要 Python、Pillow 和 FFmpeg；只运行现有成品不需要这些工具。

## 目录结构

```text
assets/   原始图片、音频和视频素材
build/    单 HTML 使用的压缩素材工作副本
dist/     最终离线单 HTML
docs/     需求、交互、验收、变更、开发和决策记录
src/      三个场景的开发源码与地图预览页
tests/    逻辑测试、浏览器测试与验收截图
tools/    素材处理和单 HTML 构建工具
```

自动检查不能替代真实手机触控、最终投放容器兼容性和完整人工试玩。发布前仍应在目标设备上走完三个场景。
